# ⚔️ صراع النجاة 3D — أون لاين (نسخة بايثون)

لعبة باتل رويال 3D أون لاين — لاعب ضد لاعب، تشتغل على الهاتف والكمبيوتر.

## التشغيل (نسخة بايثون — الأسهل)

1. نزّل Python من https://python.org
   (أثناء التثبيت علّم على ✅ Add Python to PATH)
2. افتح مجلد اللعبة بالترمنال (CMD) واكتب:

       pip install python-socketio aiohttp
       python server.py

3. افتح المتصفح على: http://localhost:3000
4. لأصدقائك على نفس الواي فاي: http://192.168.1.x:3000
   (شوف رقم IP جهازك بأمر: )

ملاحظة: server.js (نسخة Node.js) لسه موجودة إذا حبيت تستخدمها —
        نفس اللعبة تماماً، اختر اللي يناسبك.

## أون لاين لأي شخص بالعالم (مجاناً)
ارفع المجلد على GitHub ثم Render.com ← Web Service:
Build = pip install python-socketio aiohttp
Start = python server.py
